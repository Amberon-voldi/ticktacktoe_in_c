POSITION MAPPING (1D INPUT → 2D ARRAY):

Input:   0 1 2         Array:  [0][0] [0][1] [0][2]
         3 4 5                 [1][0] [1][1] [1][2]
         6 7 8                 [2][0] [2][1] [2][2]

Formula:
  row = position / 3
  col = position % 3

Example: Input 5
  row = 5 / 3 = 1
  col = 5 % 3 = 2
  → Array position [1][2]
